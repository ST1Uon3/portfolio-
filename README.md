# Portafolio — David Stiven Alvarez Mesa

Portafolio web multipágina que centraliza proyectos, ejercicios y entregas académicas de desarrollo de software. Está diseñado para mantener una estructura visual uniforme en todas sus vistas, facilitando la navegación entre categorías y el acceso rápido a repositorios y demostraciones en vivo.

## ¿Qué contiene?

El portafolio está organizado en una vista principal y páginas temáticas por área o línea de trabajo:

* **Página principal (`index.html`):** Presentación general, navegación hacia las distintas áreas del portafolio y acceso a los proyectos destacados.
* **Vistas por categoría:** Secciones dedicadas a las diferentes líneas del programa (como *Team Leader*, *Artificial Intelligence*, *Algorithmics* y *Software Development*), estructuradas mediante tarjetas individuales con etiquetas de semana y modalidad (`Group`, `Pairs`), junto con enlaces a GitHub y sitios en vivo cuando aplican.
* **Estilos compartidos (`styles.css`):** Hoja de estilos centralizada con variables de color, diseño adaptable (responsive) y componentes reutilizables.

## Enfoque de diseño y mantenimiento

* **Consistencia visual:** Todas las vistas comparten una misma paleta de colores (`--negro`, `--gris`, `--gris-claro`, `--dorado`, `--rojo`, `--beige`), tipografías y patrones de tarjetas para que la experiencia sea coherente de principio a fin.
* **Escalabilidad sin fricción:** Al basarse en tarjetas modulares y clases reutilizables, es posible sumar nuevas entregas o semanas sin alterar la estructura base del sitio ni reescribir este documento.

## Uso local

Solo necesitas abrir `index.html` en tu navegador o servir la carpeta del proyecto con un servidor local (por ejemplo, la extensión *Live Server* en Visual Studio Code).
